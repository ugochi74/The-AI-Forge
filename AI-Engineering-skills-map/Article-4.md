## Part 4: Using Coding Agents

## Author: Andrew.Nd
## Book: The AI Engineering Skills Map


### Summary


Coding agents are AI-powered tools that assist software engineers with tasks such as writing code, debugging, testing, and understanding existing codebases. Using them effectively requires proper planning, execution, and verification. During planning, engineers should understand project requirements, examine the codebase, create specifications, and break complex tasks into smaller steps. During execution, they provide clear instructions and relevant context while managing the agent's permissions and level of independence. After implementation, engineers must review generated code, run tests, identify errors, and confirm that requirements have been satisfied. Coding agents can improve productivity, but their output may contain mistakes, security risks, or unnecessary complexity. Therefore, engineers remain responsible for the quality of the final implementation. The key lesson is that successful AI-assisted development depends on effective direction, human supervision, and proper verification.
