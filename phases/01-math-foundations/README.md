## Lesson Folder Structure

Each lesson uses the following structure:

```text
lesson-folder/
├── notes.md
├── code/
├── outputs/
├── verification/
└── reflection.md
```

- **notes.md** — explanations, definitions, and important concepts.
- **code/** — practical implementations and exercises.
- **outputs/** — captured outputs from programs and experiments.
- **verification/** — test results and evidence that exercises work.
- **reflection.md** — what I understood, challenges, and areas to practise.

## Learning Workflow

1. Review the concept and understand the underlying mathematics.
2. Work through small examples before moving to more complex problems.
3. Implement the concepts in Python where appropriate.
4. Save program outputs and verification evidence.
5. Complete the lesson exercises and quiz.
6. Record the result and update the progress status.
