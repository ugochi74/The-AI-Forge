# Jupyter Notebooks

## Goal

Use notebooks to explore ideas and inspect results, then move reusable code into scripts.

## Notes

- A notebook contains code and Markdown(text) cells.
- The kernel runs code and keeps variables in memory across cells.
- Running cells out of order create hidden state and  can make a notebook fail when someone runs it from top to bottom.. Restart and run all cells before sharing.
- Use notebooks to explore and prototype; use `.py` scripts for reusable or production code.
- `%timeit` repeats a line and reports average time; `%%time` runs a cell once.


## Notes to be taken

Think of a notebook as a scratchpad for experiments: you can run a small piece of code, inspect the result, and change it quickly. A .py script is a saved program that runs in a predictable order, which makes it easier to reuse or schedule.
