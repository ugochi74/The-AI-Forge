# Data Management

Lesson source: [Data Management](https://aiengineeringfromscratch.com/lesson?path=00-setup-and-tooling/09-data-management)

## Lesson workspace

- `code/data_utils.py` — streaming preview, format conversion, Parquet loading,
  and seeded train/validation/test splitting helpers.
- `code/run_remaining_exercises.py` — MRPC cache/format/split checks and the
  two timed C4 streaming attempts.
- `outputs/` — command results and `prompt-data-helper.md`, a reusable dataset
  selection prompt.
- `verification/` — environment and practical check results.
- `notes.md` — concepts and commands covered in the lesson.
- `reflection.md` — answers to the lesson reflection questions.

Run the practical checks from the repository root:

```bash
.venv/bin/python phases/00-setup-and-tooling/09-data-management/code/run_remaining_exercises.py
```
