# Terminal and Shell — Learning Reflection

**Author:** Andrew.Nd

## What I Learned

I learned how to use terminal commands to manage files, search and filter text, redirect command output, and monitor system resources. I also learned how to combine commands using pipes and create reusable shell aliases.

## Practical Experience

I practised analysing a training log, extracting loss values, counting error messages, and saving command results to files. I also used rsync to synchronize local directories, preview changes, and verify that updated files were copied correctly.

## Challenges and Limitations

I learned to distinguish standard output from error output and to use redirection carefully to avoid overwriting important files.

Some tools were unavailable in my workplace environment. tmux and screen were not installed, Docker access required IT support, and personal SSH key generation was not permitted by workplace policy.

## How This Helps My AI Engineering Journey

These terminal skills will help me manage development environments, inspect application logs, monitor system resources, organize project files, and work more efficiently on AI engineering projects.

## Final Reflection

This lesson improved my confidence in using the Linux terminal. I now understand how basic shell commands can be combined to perform useful development and troubleshooting tasks.
