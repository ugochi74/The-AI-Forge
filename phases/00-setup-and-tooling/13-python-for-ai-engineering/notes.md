# Python for AI Engineering: study notes

The toolkit loads CSV/JSON records, creates a reproducible split, yields mini-batches, standardizes using training statistics, and classifies with centroids. Generators avoid retaining an entire collection. A fixed seed controls random data and splitting; sizes depend on dataset size and split fraction. Local exercise code covers median, streaming, matrix-vector comparison when NumPy is available, and an AST construct scan.

These are prepared study notes, not evidence of learner completion.
