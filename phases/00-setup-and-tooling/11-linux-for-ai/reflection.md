# Lesson 11 Reflection: Linux for AI

**Author:** Andrew.Nd

I learned how Linux organizes files and directories, how permissions protect files, and how to inspect users and running processes. I also practised starting and stopping a background process safely.

I used Linux commands to check CPU, RAM, swap, disk space, package information, network interfaces, listening ports, DNS, and HTTP connectivity.

The most useful part was understanding how to inspect a process by its PID and how system resources affect AI development. My machine has two available CPU cores and approximately 3.7 GiB of RAM. The high swap usage reminds me to monitor memory before running demanding workloads.

Some tools, including `tmux`, `screen`, and `nvidia-smi`, were unavailable. I also have restricted administrator access, so package installation requires workplace IT approval.

This lesson improved my confidence using Linux for development and troubleshooting. I will apply these commands when preparing environments and managing AI workloads.
